实验目标是形成完整闭环：设置 `stvec` 与时钟 → 发生 Trap → `SAVE_ALL` 保存现场 → `__alltraps` 调用 C 函数 `trap(tf)` → 分发中断或异常 → `RESTORE_ALL` 恢复现场 → `sret` 返回原执行流。本实验主要验证内核 S 态中的断点、非法指令和时钟处理；不能把 `sret` 一律理解为返回 U 态，应按保存的 `SPP` 返回。

### 修改边界与协作顺序

1. **先约定接口，随后并行实现。** 沿用 `trap(struct trapframe *tf)`、`interrupt_handler(struct trapframe *tf)` 和 `exception_handler(struct trapframe *tf)`，不改变 `SAVE_ALL`、`struct trapframe` 或课程启动/分发流程。时钟、非法指令和断点输出须符合课程测试。
2. **汇编与两个 C handler 分别负责。** 崔迪独立修改 `trapentry.S`；李子谦仅负责中断函数及其专用声明/状态，梁靖泽仅负责异常函数及其专用辅助函数。中断不推进 EPC，异常按指令长度推进 EPC，这是两条处理路径的交接约定。
3. **共同文件按函数合并。** `trap.c` 只有一个 `lab3 function2` 填空区，两人的提交可能在相邻插入处冲突；各自提交局部补丁，保留原始模块标记，并在自己函数附近增加本人 `lab3` 学号注释，不各自覆盖整个文件或把公共标记只归给一人。李子谦负责中断专用依赖及关机计数，梁靖泽负责指令长度辅助逻辑；崔迪协调一次合并，二人核对各自函数。
4. **先打通异常返回，再验证持续时钟。** 崔迪与梁靖泽先联调断点/非法指令和寄存器恢复，随后李子谦联调连续时钟与关机。三人都可先独立阅读、编写代码和准备自己的测试，但真实 Trap 返回验证需要相关模块一并完成。
5. **集中跑一次课程验收，各自修复自己的模块。** 李子谦执行干净构建和 `make grade`，三人共同检查三个评分项与日志。第 1 项同时依赖崔迪的汇编和梁靖泽的断点处理，第 2 项也覆盖李子谦的中断兜底，不能将评分项直接当作个人贡献分数。关机阈值未明确前由李子谦核对指导书/课程要求并记录依据，不自行假定具体次数。
